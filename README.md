Bank Management System

Project Overview

A Java-based Bank Management System developed using Java Swing, JDBC, and MySQL. This application provides basic banking operations through a graphical user interface.

Technologies Used
- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA

Features
- User Login
- User Signup
- Account Balance Enquiry
- Cash Deposit
- Fast Cash Withdrawal
- PIN Management
- Mini Statement

Database
MySQL is used to store user account details and transaction information.

How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Add the required MySQL Connector JAR.
4. Configure your MySQL database connection.
5. Run "main_Class.java".
